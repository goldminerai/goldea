## 5. Drift Mode + DM 모드 정책 (v3.0.6 그대로 유지)

### 5-1. Drift Block (단방향 신규 차단)
- 발동: |g_driftDisp| ≥ $50
- 동작: 추세 반대 사이드 신규 사이클만 차단
- 진행 중 사이클 마틴: 자유 (v3.0.6 정정 유지)
- 해제: |g_driftDisp| < $20

### 5-2. DM (Drift Mining) 단방향
- Drift 발동 후 DM_IDLE → DM_MINING (ATR/뉴스/세션 OK 시)
- DM 중 신규 사이클: **추세 동조 사이드만** (단방향)
- 추세 반대 사이드: 여전히 차단 (DM 활성 중에도)
- DM_MaxLight=2 (LIGHT $400), DM_MaxDeep=1 (DEEP $200)
- DM_DeepHours=4.0h

### 5-3. 단방향 vs 양방향 결정 사유
- 오늘 데이터로 검증: 단방향이 압도적 유리
- BUY 사이드 (추세 동조) 8회 청산, 작은 이익 누적
- 양방향이었으면 SELL 사이드 추가 사이클 → SO 가속
