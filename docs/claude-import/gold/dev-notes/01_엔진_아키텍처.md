> 별칭: GoldMiner, GOLD MINER, XGrind, GOLD MINER AI. (원본: 메모리 goldminer-ea)

## 정체 · 철학
- GoldMiner / GOLD MINER = XAUUSD 마틴게일 그리드 EA. MOMANTIC 플래그십 제품.
- v5.0.0 포크 개발이 현재 주력. 아키텍처는 v4.0.x → 포크 → v5.0.0(다수 세션).
- 핵심 설계 철학: 마틴/그리드 = 숏감마 엔진(횡보에서 벌고 추세 지속에 치명 노출). **진입 예측보다 손실 구조 관리**, 안전 우선(수익 최대화보다 생존). **나이(aging)는 진입 임계지 유지조건 아님**. 그라인딩은 리스크 해소지 수익 도구 아님. 랏 예산 불변(L13+ 없음).
- 마케팅 키워드 "지능형 리스크 감지"(Drift + ATR + News 3중 필터). Scavenge Mode 미사용.

## 주요 시스템
- 양방향 마틴게일 그리드, Guard Hold(뉴스/ATR/RMG 이벤트 중 레이어 추가 일시정지), Drift 상태기계(P0–P3), DDM(Daily Drift Multiplier, 랏 감축), 솔버 모드(매직 777), 교차 그라인딩(XGrind, age-latch 원칙), F1 비상 연료공급(보류), 프로핏메이커 엔진(매직 555).
- 백테스트 우회는 g_isTester 감지.
- 빌드 3종: internal / locked / broadcast.
- 기능 인벤토리는 포크 전용 기능과 병합 계보 기능을 구분(SSG/EQG 가드·SLC·MGN·EL 헷징·Z2/Z3 상태기계는 현재 포크에 부재).
- AutoLot 복리는 새 사이클 진입에서만 적용. R3 재진입 게이트는 기본 제거.
- 통합 버전 = GoldMiner 베이스 엔진 + 프로핏메이커 엔진(PROFIT No.05 진화형). 프로핏메이커: 일 5% 목표 / 쿨다운 / Day-complete 종료.
