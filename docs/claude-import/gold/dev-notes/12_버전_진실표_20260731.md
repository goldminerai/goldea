## 6. 앞선 감사에서 **여전히 유효한** 항목

정정으로 무효가 된 건 "internal 패치 누락" 하나이고, 나머지 판정은 그대로입니다.

**손대면 안 되는 것 (반증으로 기각됨)**
- `PM_Resume` 정지래치 가드 추가 → 불필요. 래치 검사는 `PM_OnTick`의 `canOpenNew`에 이미 있고 버튼은 렌더 단계에서 은닉됨
- `CalcPMProfitSince` 회계 개조 → 불필요. `from` 이전 딜 제외로 이중계상 아님, DONE 분기가 루프를 닫음
- `g_fcShutdown` GV 영속화 → 금지. `FC_PurgeRuntimeState`가 이미 GV를 지우고, 영속화하면 "재적용=재가동" 사양이 깨짐

**여전히 실재하는 것**
- `BUILD_DATE`가 세 파일 모두 `"20260727"` — 파일명 외 빌드 판별 수단 없음. 이번 오진단의 직접 원인이기도 함
- R3(Sweep 실패 로그)는 GM·앤트가드 어디에도 없음. 문서만 "구현 완료"
- 3상태 버튼의 렌더 미구현 — CLOSING 중 START가 꺼진 색인데 클릭은 동작
- 컴팩트 대시(앤트가드·한스골드) 오버레이 조건에 `DSH_FORCECLOSED` 누락

**정적 검증 통과분**(괄호 균형·정의 중복·미정의 호출·인코딩·매직 맵·F6 사다리·시간 계단·§0·SHD 구값 0건)은 변동 없습니다.
