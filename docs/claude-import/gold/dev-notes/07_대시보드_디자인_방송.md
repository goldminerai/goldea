## 가드 시스템 (16→20종)
- "왜 멈추고 언제 재개"는 이미 구현(Guard_Collect 16종·GuardSlot 구조체·Guard_Render 패널 하단). 안 보이던 원인 = 표시 결함(사유 CLR_DIM 9pt·5초 회전·ALL CLEAR가 시간 자리 덮음·총수익 22pt 시선 독점).
- 🔴 표시 공백: Guard_Collect에 EI(EI_HoldSide)·FLUSH 반대편 관문 슬롯 없음 → 신규 막혀도 화면 ALL CLEAR([[03]] 진입 저조 직결). 신규 4슬롯 추가(EI·FLUSH-GATE·PM·SOLVE) = 20종. **EI 슬롯이 최대 성과**.
- CRUSHED = 일일 손실 한도 손절(기본 30%, 발동 시 전량 청산+당일 차단, **자정 자동 리셋**). HARVEST(수익목표 달성)만 영구. ⚠ 주석 "CRUSHED 영구" 오기 → 자정 리셋으로 정정.

## 팔레트/디자인 시스템 v2 (design-system)
- 촌스러움 원인: 색 8~9계열 공존(시안/블루가 웜 골드와 충돌)·전부 고채도 위계 없음·골드가 형광 노랑(주범)·배경 탁한 갈색.
- **글씨 규칙**: 규칙1 값은 볼드·라벨은 레귤러(예외 없음) / 규칙2 크기 4단(26/18/12/8, +TOTAL% 16pt 신설) / 규칙3(7/20 개정) **라벨 회색 금지** — CLR_BRIGHT 흰색 또는 유채색, 위계는 크기·볼드로만.
- 대비 실측(WCAG, 배경 #0D0D0E): CLR_DIM #6E6E70(3.82)·CLR_PROFIT #2F7D4F(3.86)·CLR_LOSS #AA4642(3.39) 전부 AA 미달 → CLR_DIM #9B9B9D(7.0)·CLR_PROFIT #3FA268(6.09)·CLR_LOSS→CLR_LED_HALT. 빨강은 명도 낮아 2단 분리 불가 → 빨강 1개 원칙, 초록만 2단.
- 골드 램프(심심함 해법): 색 계열 안 늘리고 골드 명도를 층으로 — #D4AF37(주)→#8A7230(헤더선)→#7A6528(헤어라인)→#3A3320(카드 보더)→#171208(TODAY 배경). CLR_DIV를 밝히면 카드 테두리까지 튀므로 별도 상수 분리.
- V1 레이아웃 Y맵(222×380, 7/20 v4 재배치): BRAND16 · TOTCARD 30~96(라벨36/금액50 26pt/수익률80 16pt) · 아크 top100 중심162 · GPCT138/GNUM162/GBLK176(흰색) · 지표 198(16pt)/216(12pt 흰색) · 헤어라인232 · 레이어242 · 3일 가로 1줄 270(날짜262/% 280 16pt·부호별 초록빨강) · GCARD 300~338(ALL CLEAR 310 16pt/도트330) · 헤어라인350 · 푸터360. 라벨 전부 회색→흰색.
- 아크 채움 분모(사장님 확정): HARVEST ON이면 (BALANCE−CREDIT)/HarvestAmt×100 else blockProgress. 링=진행 중 단위(프로세스), 아크 안 숫자=누적 결과(둘이 다른 게 정상). 링 꽉 차면 EA 실제 정지.
- 주말 제외 이미 정상(GetTradingDay가 주말→금요일 역산). 3일 이력은 오늘만 골드·나머지 딤.

## MQL5 UI 제약 (반복 확인)
- OBJ_LABEL·OBJ_BUTTON = 텍스트 1개·색 1개(2색 2영역 불가 → 객체 분리). 삼각형·회전 도트는 객체 2개 겹쳐 그리기.
- **전역 변수는 선언 지점 이후에만 참조 가능**(함수는 2-pass) → 뒤에 선언된 전역은 헬퍼 함수로 감싸 우회. 지역 변수도 선언 지점 이후만.
- 비활성 전환 정리는 접두사 화이트리스트 → 신규 객체는 반드시 **L_ 접두**(AG_L_이 되어 자동 편입). 유령 객체 방지.
- 픽셀 이동(-3000) 숨김은 시간/가격 좌표 객체(HLINE·OBJ_TEXT)에 무효 → 명시 삭제 필요.
- 폭 정합(자): 12pt ≈ 9.2u/자(pt당 0.767u). pt 바꾸면 그 줄 글자수 예산도 pt비로 환산(예산 상수에 측정 당시 폰트 주석).

## 시공 진행 S1~S8 (7/17~7/18)
- 4단계 분할(S1 팔레트+LED / S2 가드슬롯 / S3 상태창+레이아웃 / S4 레일). S1은 #define 이름 유지·값만 별칭 수렴(폐기 심볼 삭제 시 에러 방지). S6 영업지표 3칸(PF│TRADES│UPTIME, 기존 계산 재사용). S7 TOTAL 라벨 복구+상태창 배경 카드. S8 컴파일 에러(선언 순서)+회귀 버그(신규 카드 화이트리스트 누락→L_ 접두 규약)·좌표 버그(DDM 헤어라인 관통).
- 패치 사고 교훈: 삭제 범위가 `{`만 먹고 `}` 남겨 중괄호 파손 → 제거 구간 자체 중괄호 균형 assert. **파이썬 CRLF 함정**: 텍스트모드 read가 \r\n→\n 변환 → split('\r\n') 전파일 1줄화 → 주석 오염. 해법 = tr -d '\r' LF 통일 후 패치 → CRLF 복원.
