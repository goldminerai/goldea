## ANTGUARD GOLD (앤트가드)
- ANTGUARD GOLD = GoldMiner 엔진 뚜껑갈이. 엔진 로직 동일, 겉모습만 다르게. 정식 명칭 "ANTGUARD GOLD"(헤더 한 줄, GOLD는 헤더에만·푸터는 ANTGUARD).
- **매직 5종 분리**(2026-07-21, 뚜껑갈이 위장 — 매직은 거래내역에 노출): 메인 880604/PM 880605/LHEDGE 880606/SOLVER 880607/WKL 880608. 구 202604 관리계좌는 LEGACY_MAGIC 스위치로 승계. 리브랜딩 GOLDMINER→ANTGUARD·GM→AG·GMSOL_→AGSOL_ (GM_ 코드식별자는 안 건드림).
- **버전 체계 독립**(v3.32부터, 골드마이너 5.5.2 상속 번호와 분리). #property version + #define EA_VERSION 두 곳만 고치면 전 표시 자동반영(EA_VERSION은 GV·persistence 키에 안 쓰임, 재번호 안전 — 포지션 연속성은 매직이 지배).
- **2빌드**(단일소스 #define DIST_BUILD 분기): 내부판(라이선스 off·전체 기능) / 배포판(백테스트 차단 MQL_TESTER→INIT_FAILED·SOLVE/BOOSTER 숨김·Inputs 축소=계좌유형+모드+SL+수익목표). 배포판 명명 _locked_. 라이선스는 DIST와 무관 별도 축(per-customer 출고).
- **대시보드 = 스파크라인**(원형게이지 아님 — 차별화): ANTGUARD 헤더 + 계좌유형자동감지·LOGIC버전 + TOTAL/RETURN + 수익추이곡선+개미 중앙 + SPLIT3 상태카드 + WIN/PF/TRADES + 푸터·모드배지 + 버튼덱. 활성 상태 = "RUNNING".
- **개미 마스코트 3종**(모드 연동): AGGRESSIVE(태권도개미/레드) / NORMAL(양반개미/골드·기본) / SAFE(턱시도개미/그린). 32bit BMP #resource(PNG는 MT5 로드 실패). 접두어 AGX_. 좌표·크기·개미는 AGX_S(=BASE×DPI/96) DPI 자동대응, 폰트만 AGX_BASE 0.667(폰트 이중확대 금지가 핵심).
- **버튼**: RESCUE BUY/SELL(구 SOLVE)·BOOSTER(풀폭 진행바 겸용, 목표 $300 고정)·SL 토글(ON초록/OFF주황·persist)·CLOSE ALL(2단 TAP AGAIN→RESUME 3상태, 계좌 전체 청산+STOPPED persist, 재개=버튼 or EA 재부착).
- **이식 결함 이력(lessons L-포트1~13)**: L1 개미/차트 실종 진범 = OnInit ResourceFree 한 줄(static 캐시가 "구웠다" 기억 → 삭제된 리소스 가리킴, MT5 static은 input변경 OnInit엔 리셋 안 됨) / 스파크 색 강제 재물림(BMPFILE 재설정) / 러닝 배지폭(글자당 7→11) / 호출순서(DrawSkeleton이 ComputeState보다 먼저 → STARTING UP 고정) / clrNONE 투명버튼이 버튼 자체를 안 보이게 함 / Inputs 라벨 길면 값 칸 밀림 / bool→AG_SWITCH enum / 매직 동일=탄로 / 업그레이드 버튼플로우 감사 / 개미 이중테두리(BMP 내장 흰테두리 + EA EDGE 덧그림 → EDGE=0) / 개미 크기(AGX_ANT_H에 AGX_S 누락 → 170px 원본 크기, 수정 113→138px) / 스파크라인 표본저장→계좌 거래내역 재구성(HistorySelect 90일, F7·재부착·버전업 무관).
- **Inputs 앤트가드 스타일**(v5.5.2): Risk Mode 3단계 enum(HIGH/MID/LOW)·전부 영어화(Rescue·Night Lock·Weekend Lock·Layer Hedge)·ANTGUARD는 그룹 섹션헤더에만·영어(한국어) 병기·AG_SWITCH 토글. DEFENSIVE 입력 숨김(로직 유지). MT5 Inputs 창은 시스템폰트라 글씨체 변경 불가.
- **버튼 플로우 감사 F1~F5**(v3.33): F1 정지 중 RESCUE/BOOSTER 차단 / F2 CloseAll에 LHEDGE_ResetAll+FC_PurgeRuntimeState(C5 GV 좀비화 방지) / F3 해결사 BE선 스윕 예외 / F4 계좌 전체 청산 AGX_SweepAccountFlat / F5 OnTick 정지 래치(2초 주기).
- 버전 계보: GoldGuard(요새/볼트, 2026-04) → AntGuard v1.0~1.5(초기, 매직 202603) → v5.4.0(정본) → v5.5.2(정본) → v3.32(재번호+매직분리) → v3.33(GoldMiner v5.5.3 엔진) → v3.34(v5.5.4 엔진 + 4.0.3 프로파일). 최신 정본만 관리.
- 스킬 = antguard-gold-dev(SKILL.md + references: reskin-recipe·dashboard-spec·lessons).

## HansGold V1 (한스골드 — HIS INVEST 전용 화이트라벨)
- HansGold V1 = 고객사 **HIS INVEST** 전용 화이트라벨(XAUUSD 마틴게일 그리드). 이중 빌드 HIS_INVEST(외부)/INTERNAL(내부) — 정확히 3개 define 차이(FIELD_STEALTH·LIC_CUSTOMER·LIC_USE_SERVER).
- **뚜껑갈이 고정 규칙**(사장님 확정 7/16): 새 GoldMiner 버전 주면 GoldMiner 엔진 + HansGold 뚜껑으로 매번 재빌드. GoldMiner 메인 기능 전부 그대로. 한스골드를 따라가는 건 딱 4가지: ①대시보드 ②외부변수창 ③이름들 ④설정(디폴트). **흡수 원칙**: 고유 기능이 엔진에 흡수되면 엔진 소속 → 레시피로 재추가 금지(중복정의=컴파일 에러), 디폴트만 한스골드 방식. 뚜껑은 버전마다 얇아짐. 베이스는 항상 internal 변형.
- 🔴 불가침: base MagicNumber = **202604 절대 불변**(GoldMiner와 동일). 매직 맵 base 202604·SOLVER 777·PM 555·LHEDGE 111·WKL 999.
- 현재 마스터: HansGold 5.5.2 = GoldMiner v5.5.2 internal 엔진 + 한스골드 뚜껑. 계보 v4.1.0(고유)→5.3.0(GM 5.3.1)→5.4.0→5.5.0(+배포봇 5건)→5.5.2.
- 뚜껑 레시피(v5.5.2): 이름 블랭킷 치환(MOMANTIC→HANSGOLD ~467곳, 잔재 0)·copyright "HIS INVEST"·BRAND "HAN'S GOLD V1"·태그 "HG". 대시보드 DASH_COMPACT ON·계좌 식별줄·러쉬 3칸 그리드. Inputs 고객 12개/5그룹(나머지 const 숨김). 설정 LOT_SAFE·8시락 ON.
