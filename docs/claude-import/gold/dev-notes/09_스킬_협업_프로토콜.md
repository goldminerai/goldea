## 필수 워크플로 (사장님 스타일 — 절대 규칙, 요약)
1. 설명 → 컨펌 → 코딩(어디가 바뀌고 무슨 역할인지 변경표 먼저, 사장님 발의 개념은 복창).
2. MQL 언어·브로커 제약 준수(최소랏·랏스텝·INVALID_STOPS·PositionClosePartial 잔여).
3. 패치 = 파일 직접 재작성 금지, python 유일 앵커(count==1 assert) 치환. CRLF 보존.
4. 정적 검증 세트(괄호 3종 균형=원본 대비 변화 0 / 신규·폐기 심볼 배선 수 / 함수 중복·미정의·미호출 0 / 신규 참조 심볼 선언 확인 / 모지바케 0).
5. 검증 사다리: F7 컴파일(사장님) → 파이썬 행동 시뮬(정적만으로 끝내지 않음) → 백테스트(씨앗 필수) → A/B 판정.
6. 이중화: 체크포인트 mq5 + 개발명세서 md를 outputs에 저장. 재개법 = "md + 최신 체크포인트 업로드".
