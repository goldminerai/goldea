# GOLD LINK — 위기 청산 커맨드 센터

> (원본: 메모리 goldlink-command-center) 정본 문서 GOLDLINK_개념설계원장_20260725.md.
> 넥서스 NEXUS-LINK를 골드마이너에 이식한 위기 전역청산. TEST 빌드(GL-A판) 탑재·백테스트 판정 완료, 라이브 보류.

## 정체성 (확정)
- GOLD LINK(GL) = 위기 청산 지휘 커맨드 센터(예외 로직 아님). 평시 취침, 계좌 위기 시 청산 지휘권 넘겨받아 계좌 전체 뇌관 총력제거, 위기 지나면 반납. 각 기계는 위기 중 안 멈춤(청산 우선권만 빌림, 재진입해 연료 재생산).
- **본질 = FIFO 교정 장치**: 각 기계는 오래된 랏부터 청산(FIFO=최고참). 전제 "오래된=먼저물린=가장위험"인데 꼬이면(방향전환·리필·방패전개) 오래된 게 먼 자리 아님 → 먼 뇌관이 뒷순번 밀려 방치. GL이 FIFO 무시하고 "지금 제일 위험한 자리" 직접 지목해 실시간 교정.
- 뿌리 = 넥서스 NEXUS-LINK(멀티종목 합산청산). 평시 각자 자율 → 위기 시 0순위 승격.

## 뇌관 선정 (핵심)
- 뇌관 = 매직무관 현재가서 가장 먼 손실 하나(202604·555·999 어디든) / 진영 = 손실 합 큰 쪽(랏 아님) / 연료 = 매직무관 수익 포지션 합산+ 한도까지.
- 손익 부호가 부채/방패 자동구분(수익=연료·손실=불참) → 방패 판정 불요. 555·999 물려도 자동 대상(고아 방치 없음).
- ⚠ "랏·레이어 많은 쪽"으로 고르면 안 됨(승자를 뇌관 오인). 참조A: 진영별 머릿수 판정 = 두 창 100% 오답(머릿수 많은 쪽=승자). Σ(랏곱거리) 지표도 방패 오염으로 틀림. 개별 손익부호만 봐야 방패 판정 소멸.

## 위기 스위치 (7/25 재정의)
- 계좌 원금 대비 −$5,000 도달 시 활성 → **활성 후 최소 4시간 무조건 가동**(그 사이 −$4,000 이내 회복해도 계속) → 4시간 뒤 재판단 → 해제 후 다시 −$5,000 찍으면 재활성. (원장 구안 "−4,000 복귀 4시간 연속 유지"와 다름 — 4시간이 회복 요건이 아니라 **최소 가동 시간**.)
- 임계 = 복리 연동: 단리 시 $5,000 고정 / 복리 시 비례(5000 × GetActiveLot 배수 재사용).

## 연료·청산 규칙 (넥서스 직역)
- 수익 손익 큰 순 합산, 개별 손실 만나면 즉시 중단, [뇌관+수익다리] 동시청산=항상 순수익(§0 합치). 한 번에 가장 곪은 것 하나씩(**뇌관 = 회차당 하나만**, 연쇄 아님).
- 연료 한도 = 약수익 식 하나(0.5×랏×100, 순기여=손익−몫, 발사=묶음 순기여≥0). 연료는 뇌관 덮는 순간 중단(net<=0 break). 새 상수·지표 불필요. 연료 없으면 발사 불성립, 조용히 대기.
- 집행 주기 상수 불필요("조건이 곧 주기"). 기존 쿨다운 미상속, §16 게이트만 상속.
- 청산 = EXITTXN 사후감사 E4 재사용(닫고-확인-고아정리-재확인-해제) = 고아 자동방지.

## 교차점 5종 / 캡 / 손절
- ①넘겨받기(ExitTxn_Begin) ②공존(ExitTxn_Claimed) ③돌려주기(리셋 아님, 각 기계 실물 재스캔) ④캡 해제(청산경로만 우회, 진입 정상캡) ⑤진영 전환(선정·집행 분리, 집행 직전 재확인).
- 캡 = 해결사 진입캡, 위기 중 한도의 2배(SOLVER_MAX_CYCLES 4→8). DDM_STAGE·ML_TOO_LOW 게이트는 미해제.
- MSL(손절)=UseCrushGuard, 대다수 OFF. 손절 OFF면 GL 유일 대응(충돌 없음), ON이면 GL 1차방어+MSL 최후안전판.
- 진입 폭주 걱정 없음: GL이 캡 풀어도 DDM·ATR Guard·증차간격게이트가 진입 속도 제어("청산은 총동원, 진입은 신중").

## 구현 (7/25 완료, F7 대기)
- GL-A판 = GoldMiner_v5_5_4_TEST_A.mq5(EA_VERSION 5.5.4A-TEST). 입력 5개: T_GL_ENABLED(false) / T_GL_SIDE_LOTS 2.0 / T_GL_TRIGGER_USD 12000 / T_GL_REL_LOTS 0.8 / T_GL_REL_USD 6000. GL_Update 하이브리드(시작 OR·해제 AND·4h 폐지). 대시보드 GT_GL 슬롯(가드 21종). internal·locked 무변경.
- 자기감사 수리: F1 GV 이름 무접미(다계좌 오염) → GL_GVName 접미. F2 해결사 상태 유효캡 반영. 대시보드 D1~D5.
- 연료 제외 목록 분석 → **철회**(사장님 반론: "모든 게 리스크 해소, FIFO 아닐 경우 보완이라 목표대로 동작"). 방패 강탈은 이미 수용된 트레이드오프, xgArmed·555는 예약 가드 흡수, 장부는 정상. 신규 설계는 원장 4개 그대로(캡 복귀 타이밍·캡 청산경로 우회·위기 스위치 GV 영속·휴장 게이트 상속).

## 백테스트 판정
- 5월 A/B(5/6~5/13 레인지): GL OFF +4,091·EqDD 9,934 / GL ON −2,364·EqDD 10,882(BalDD 6,975 전액 종료청산). GL 묶음 자체는 전부 순+(집행 무결). 동시각 에쿼티 $6,455 OFF 우위 = **GL이 연료·방패 앞당겨 소진해 위기 미완**. 3막 구조(1막 5/6 연료 조기소진 → EqDD 최대치 첫날 / 2막 5/7~11 뇌관 제거로 얕음 = GL 의도 실증 / 3막 5/12 재소진으로 마감 정리 실패). **결론: 5월 레인지에선 GL ON 손해(원장 기회비용 예측 실증)**.
- 4월(추세) 캘리브레이션: 구스펙 −5k는 평시 7발 연료 선소진이 위기를 2배로 키움(−5k 병리 재현). 신 스펙(랏≥2.0×배수 OR 부동≤−12k×복리 / 해제 랏≤0.8×배수) 4월 검증: 진짜 위기(4/21) 분 단위 정확히 짚음, 5월 완전 취침.

## 넥서스 원형 대조 (참조)
- 넥서스는 전면 '개수·단계' 문법(달러 임계 부재). NEXUS LINK 발동 = 위기 깊이가 아니라 '연료 준비 완료'(수익 파이프라인 2개+ ∧ 합산 ≥ MainLot×NexusProfit 400). 청산 = Main first LP 1개만("가장 먼 손실 뇌관 하나" 원본).
- 넥서스 해제 3종: 시간(연속진입 제한 후 4시간 자동 = GL 4h 원조)·구조 소화(개수)·극점 위치 85%/15%.
- 시사점: 랏/레이어 기반 시작·해제는 넥서스 문법으로의 회귀라 정통성 있음.

## 리스크·기회비용 (반드시 인지)
- 본질 = "큰 낙폭 위험"을 "작은 확정+상방 포기"와 맞바꾸는 보험. 위기 크고 곧 반등 안 할 때만 값어치(4월형 추세 O·레인지 X).
- 리스크: 연료 강탈로 방패 뚫림 / 연료 소진 후 뇌관만 잔존(일방통행) / 동시청산 시장충격·§16 부하 / 경계 판단 지연.
- 기회비용: ★"버텨서 되돌림에 크게 먹을" 기회 포기(최대) / 연료 앞당겨 소진 / 빈번청산 거래비용 / 새 버그 표면(교차점 5개).
- → 선택적 활성화(TEST 전용 입력)로 탑재, internal·locked 미탑재.
