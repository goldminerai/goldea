# MOMANTIC 대시보드 프로젝트 현황

## 📅 최종 업데이트: 2024.12.12

---

## 🎯 프로젝트 개요

자동매매(EA) 서비스를 위한 3가지 대시보드 시스템 개발:
1. **영업용 대시보드** - 고객 유치 & 실적 공개용 (PUBLIC/INTERNAL 모드)
2. **모니터링 대시보드** - 실시간 계좌 모니터링용 (MINI/LITE/FULL 뷰)
3. **어드민 대시보드** - 관리자용 통합 관리

#### 차트 탭 시스템
1. **잔고 추이**: 월별 잔고 라인차트 + MDD 영역 + 인디케이터
2. **수익 현황**: 월별 수익 바차트 (양수:초록, 음수:빨강)
3. **종목 분석**: 심볼별 도넛차트 + 수익 바

#### 인디케이터 기능 (잔고 추이)
- 기본: 차트 끝점에 현재 잔고/수익 표시
- 호버: 마우스 위치의 데이터 포인트 값 표시
- 마우스 떠남: 끝점으로 복귀

#### 하단 섹션들
- **📊 성과 분석**: 심볼별/요일별 수익, 위험 지표
- **💹 최근 거래 내역**: 테이블 (티켓, 심볼, 유형, 랏, 손익 등)
- **📜 입출금 내역**: 아코디언
- **🎁 공유 & 레퍼럴**: 공유카드, 카카오톡, 링크복사, 추천코드
- **🔔 알림 설정**: 텔레그램 연동 UI (NEW!)

## 🔜 다음 작업: 모니터링 대시보드

### 📋 기본 구조 (MINI/LITE/FULL 뷰)

#### MINI 뷰 (위젯형)
- 현재 잔고
- 일일 손익
- 활성 포지션 수
- 마진 레벨

#### LITE 뷰 (요약형)
- MINI 내용 +
- 실시간 포지션 목록 (간략)
- 오늘 거래 내역
- 간단 차트

#### FULL 뷰 (전체형)
- LITE 내용 +
- 상세 포지션 정보 (SL/TP, 스왑, 커미션)
- 히스토리컬 차트
- 성과 분석
- 알림 히스토리

### 🔗 영업용 대시보드와 연동 포인트
1. **계정 데이터 공유**: 동일한 accounts 데이터 구조 사용
2. **알림 설정**: 모니터링에서도 알림 설정 접근 가능
3. **실시간 데이터**: 모니터링 → 영업용으로 데이터 피드

### 💡 모니터링 핵심 기능 (구현 예정)
1. **실시간 업데이트**: WebSocket 또는 폴링
2. **멀티 계좌 모니터링**: 여러 계좌 동시 감시
3. **위험 경고 시스템**: 마진콜, 대형 손실 즉시 표시
4. **거래 히스토리**: 필터링, 검색, 내보내기
