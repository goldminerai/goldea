# GoldMiner v5.5.2 — 변경점 정리

**대상:** GoldMiner (XAUUSD 마틴게일 그리드 EA)
**기준:** v5.5.0 → v5.5.2
**날짜:** 2026-07-19
**규모:** 16,543행 → 16,737행 (+194)

---

## 한눈에

v5.5.0에서 v5.5.2까지는 **두 단계**로 나뉩니다.

| 버전 | 성격 | 핵심 |
|---|---|---|
| **5.5.0** | 엔진 전면 개편 완료본 | 랏 사다리·FLUSH 관문·백테스트 A~M |
| **5.5.1** | 안전장치 | 강제청산 정책 v2 흡수 |
| **5.5.2** | **대시보드 전면 리뉴얼** | 이번 작업의 본체 |

즉 v5.5.2의 변경은 **거의 전부 대시보드(세로 풀패널) 개편**입니다. 매매 로직·진입·청산 알고리즘은 건드리지 않았습니다. 화면에 안 보이던 상태를 드러내고, 촌스럽던 색을 정리하고, 정보 위계를 다시 잡은 것이 전부입니다.

> **매매 동작은 v5.5.0과 동일합니다.** 백테스트 결과가 바뀌지 않습니다.

## 1. 팔레트 — 촌스러움 제거

### 문제였던 것
- 색이 **9계열** 공존 (골드2·앰버·그린·시안·레드·블루·핑크·보라·크림). 웜 골드와 쿨 시안/블루가 충돌.
- 골드가 **형광 노랑**(`#FCD34D`)이라 싸구려 느낌.
- 라벨 회색(`#6E6E70`)이 배경 대비 **3.82:1** — 사실상 안 보임.

### 바뀐 것
- **모노 골드 단색 체계**로 수렴. 색 계열을 늘리는 대신 골드의 명도를 층으로 쌓음: `#D4AF37`(주) → `#8A7230`(헤더선) → `#7A6528`(헤어라인) → `#3A3320`(카드 보더).
- 클래식 골드 `#D4AF37`로 교체 (형광 노랑 폐기).
- 라벨 대비 교정: `#6E6E70`(3.82) → `#9B9B9D`(7.0). **"그레이색 안 보임" 해결.**
- 수익 초록 대비 교정: `#2F7D4F`(3.86) → `#3FA268`(6.09).

### LED 3색 체계 (신규)
상태를 **"포지션이 살아있나"** 기준으로 3색 판정:

| 색 | 의미 | 예 |
|---|---|---|
| 🟢 초록 `#46C06A` | 신규 진입 가능 | ALL CLEAR, MINED, PM, 해결사 |
| 🟠 주황 `#E08A2E` | 신규만 차단·기존 관리 중 | NIGHT, NEWS, EI, SETUP, FLUSH 관문 |
| 🔴 빨강 `#E04A44` | 전량 청산·구동 정지 | CRUSHED, HARVEST, 강제청산, 서버정지 |

> **기존 LED 배정 7건 교정:** OFF HOUR·CLOSE·RAPID가 빨강이라 **정상 운영 중에도 매일 빨간불**이 떠서 진짜 정지와 구분이 안 됐음 → 주황으로 정정.

## 2. 가드(상태 표시) — 안 보이던 상태 4종 추가

"왜 멈추고 언제 재개되는지"는 원래도 구현돼 있었지만, **일부 상태가 화면에 안 떴습니다.**

### 신규 가드 슬롯 4종

| 슬롯 | 무엇 | 왜 중요 |
|---|---|---|
| **EI** | 뉴스 이벤트 진입 차단 | ★ 이게 최대 성과 — 차단 중인데 화면엔 "ALL CLEAR"로 떴었음 |
| **FLUSH-GATE** | 반대편 관문 대기 | 신규가 막혀도 화면엔 안 보였음 |
| **PM** | 프로핏 메이커 동작 | `MINING $82/$201` 진행률 |
| **SOLVE-B/S** | 해결사 동작 | 매수/매도 해결 상태 |

**EI 슬롯이 핵심입니다.** 뉴스 차단(`EI_HoldSide`)은 다른 어느 조건에도 안 잡혀서, EA가 진입을 막고 있는데 화면은 "정상"으로 표시됐습니다. 하루 거래 수가 예상보다 적던 원인과 직결됩니다. 이제 차단 사유와 다음 이벤트명이 표시됩니다.

### 상태창 = 1줄 + 회전
- 상태를 한 줄로 압축 (아이콘 + 내용 + 재개 시간).
- 가드가 여러 개면 5초마다 회전, 회전 도트(`● ○`)로 개수 표시.
- 재개 시간은 우측 고정 (절대 안 잘림).

## 3. 레이아웃 — 세로 풀패널 재설계

### TOTAL 카드 (신규)
- 총수익을 **카드로 감싸** 최상위 정보로 격상. "이걸로 로직을 평가받는다"는 위계.
- 금액 26pt 볼드 + 수익률 16pt + 라벨.

### 원형 아크 게이지 (정체성 유지)
- 하단이 열린 **270° 개방 아크** — EA의 시각 정체성. 유지.
- 아크 안 = **오늘(TODAY)** 수익률·수익금.
- **아크 채움 기준:**
  - HARVEST ON → 목표 금액 대비 (다 차면 EA 정지 = 게이지와 동작 일치)
  - HARVEST OFF → 블럭($200) 단위로 차고 비우기 반복

### 영업 지표 3칸 (신규)
`PF │ TRADES │ UPTIME` — 신규 데이터 추적 없이 기존 계산분 재사용.

### 우측 버튼 레일 (신규)
- 버튼을 패널 **우측 세로 레일**로 이설. 기존엔 패널 위쪽이라 **차트 가격 텍스트와 겹쳤음.**
- 3단 색: 회색 아웃라인(불가) / 골드 아웃라인(가능) / 골드 채움(작동 중).

### 최근 3거래일
- 가로 1줄로 압축 (`M17 M16 M15`).
- **주말 자동 제외** — 골드 장이 멈추는 토·일을 건너뛰고 직전 거래일 3개.

### 헤어라인 · 방향 삼각형
- 섹션 구분 골드 헤어라인 3개 (은은한 강조).
- BUY/SELL 방향 삼각형에 색: ▲초록 / ▼빨강, 포지션 없으면 회색.

## 4. 글씨 규칙 (신규 표준)

앞으로 대시보드 작업의 기준:

1. **값은 볼드, 라벨은 레귤러.** 예외 없음.
2. **크기는 지정된 단만:** 26 / 18 / 16 / 12 / 8.
3. **라벨색은 `#9B9B9D`(7.0:1) 이상.** 그 이하 명도 금지.

## 매매 로직 변경 없음 (확인)

이번 버전에서 **진입·청산·물타기·랏 계산·백테스트 결과는 변하지 않았습니다.** 대시보드 표시 계층과 상태 수집만 손댔습니다. 기존 계좌·설정 그대로 교체 가능합니다.

### PM(프로핏 메이커) 정지 동작 — 참고
정지("PM STOP")는 **소프트 마감**입니다:
- **포지션 없음** → 즉시 완전 정지.
- **포지션 있음** → 신규 진입만 차단, 기존 포지션은 익절(TP)까지 관리 후 다 닫히면 정지.
- 손실 포지션을 강제 손절하지는 않음 (즉시 전량 청산은 CLOSE ALL).
