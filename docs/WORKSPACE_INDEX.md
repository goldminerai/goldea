# 골드·FX 작업 자료 인덱스

2026-07-31 기준으로 PC의 작업 폴더와 Claude 로컬 작업 흔적을 읽기 전용으로 검색해 정리했다.

## 분류

- 골드 EA: GoldMiner, GoldGuard, GoldSun, HansGold, GoldFerrari, PrimeGold, S_BOMB
- FX/멀티자산 EA: NEXUS, SideJobMaster, FP_TRADER, FX/Forex 명칭 파일
- 서버·연동·사업 문서: MOMANTIC, allthatea, EA 공통 규격, 라이선스, 웹훅, 인수인계 문서
- 검증 자료: MT5 거래 리포트, CSV/Excel 백테스트·거래 기록

## 보관 위치

- 공개 작업본: `src/mt5/`, `docs/claude-import/`
- PC 원본 보관본: `_local_archive/` (Git 제외)

Claude Desktop의 대화 DB와 캐시는 앱 내부 형식이라 그대로 복사하지 않는다. 대화에서 생성된 실제 파일과 사용자가 내보낸 문서를 기준으로 정리한다.

## 주의

원본 자료 중 일부 EA에는 인증값이 코드에 들어 있다. `_local_archive/` 밖으로 이동하거나 GitHub에 push하기 전에 키를 분리해야 한다.
