# 개발 에이전트 (goldea)

자동매매 EA 개발의 **관리·감독·설계**를 담당하는 서브에이전트 8종.
사장님 절대 규칙(설명 → 컨펌 → 코딩 → 검증 사다리)을 사람이 매번 챙기지 않아도
자동으로 걸리게 만드는 것이 목적이다.

## 파이프라인 (호출 순서)

```
[제안]
  ↓
1. rulebook-auditor    확정 규정과 충돌하나?          ← 코딩 전
2. defect-historian    과거에 실패한 부류 아닌가?      ← 코딩 전
3. change-spec         변경표 작성                    ← 컨펌 전
  ↓  ★ 사장님 컨펌
4. [패치]              유일 앵커 str-replace (count==1)
5. static-verifier     괄호·배선·인코딩 기계 검사      ← 패치 직후
6. whitelabel-porter   5파일 전수 반영 확인            ← 패치 직후
  ↓  ★ F7 컴파일 (사장님)
7. behavior-sim        상태기계 케이스 검증
  ↓  ★ 백테스트 (씨앗·대조군 필수)
8. backtest-forensics  리포트 법의학 · A/B 판정
  ↓
9. skeptic             결론 반증                      ← 보고 전
  ↓
[보고]
```

## 각 에이전트가 막는 실제 사고

| 에이전트 | 막는 것 |
|---|---|
| `rulebook-auditor` | 폐기된 SHD 구값(만재 2.78·L11 ×8.3)을 "불가침"으로 믿고 작업 |
| `defect-historian` | 이미 기각·철회된 처방 재생산, 기저율 무시한 신규 장치 투입 |
| `change-spec` | "이 장치가 떠받치던 것"을 안 묻고 제거 (4연속 동일 실수) |
| `static-verifier` | 앵커 실패·배선 누락·괄호 붕괴를 F7까지 못 잡고 가기 |
| `whitelabel-porter` | 일부 빌드에만 반영되어 나머지가 구버전으로 잔존 |
| `behavior-sim` | 영구 감금 분기(부스터 CLOSING 잠김, 솔버 active 고착) |
| `backtest-forensics` | 부호 규약 오독으로 사망 원인 오진, 대조군 없는 판정 |
| `skeptic` | 추정을 확정처럼 보고, 후견지명 반사실, 오진단 후 수리 |

## 원칙

- **원전은 이 레포다.** `docs/claude-import/gold/GOLD_INDEX.md` + `dev-notes/` + `skill/`.
  외부에 떠다니는 zip이 아니라 여기를 읽는다. 계보가 갈리지 않게 하는 유일한 방법이다.
- **SHD 계보는 폐기다.** 구값이 문서에 남아 있으면 그건 대체 이력이지 유효 규정이 아니다.
- **판정 등급을 항상 표기한다**: `[코드확인]` / `[데이터판독]` / `[추정]`.
- **런타임 판정은 F7이 유일**하다. 정적 검증 통과는 컴파일 전 최소 조건일 뿐이다.
- **라이브 투입은 검증 사다리 통과 전 금지.**
