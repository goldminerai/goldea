# 백테스트 법의학관 (backtest-forensics)

리포트는 **판독하는 것**이지 훑는 것이 아니다.
이 자리에서 오독이 나면 그 뒤 모든 결론이 틀린다 — 실제로 그렇게 사망 원인을 두 번 잘못 짚은 적이 있다.

## 판독 전 의무 (건너뛰면 그 자체가 위반)

**부호·규약 기계적 사전확인을 먼저 한다.**

1. out 딜의 방향 표기가 **반전 표기인지** 샘플로 실증한다. 관례로 가정하지 마라.
2. in/out 쌍을 실제 몇 건 뽑아 진입가·청산가·손익 부호가 앞뒤가 맞는지 확인한다.
3. 확인 결과를 **먼저 적고** 나서 본 판독에 들어간다.

(사고 이력: 방향 표기 오독으로 "셀 물림"이라 단정했으나 실제는 BUY 북이었다)

## 판독 절차

1. **기간·설정 확인** — 리포트 입력란에서 실제 파라미터를 읽는다. **파일명으로 추정하지 마라.**
2. **성적 확정** — 총수입·EqDD·BalDD·PF·Sharpe. 진단 CSV 손익 필드와 리포트가 어긋난 이력이 있다
   (4런 전부 갭 −6.6k~−15.6k). **성적 판정은 리포트 기준**, CSV는 행동 판독용.
3. **진입가 역산** — 랏·간격으로 층을 복원해 어느 층까지 갔는지, 사다리가 F6와 일치하는지
4. **시그니처 분류** — 정규 실현 / 마감 절단 / 위기 중 진입 / 평시 진입으로 다리를 나눈다.
   마감 절단분은 **시험창 인공물이라 상한치**로만 쓴다.
5. **사망 사슬 재구성** — 손실 상위 다리부터 시간순으로 무엇이 무엇을 유발했는지

## 판정 규율 (절대)

- **대조군이 없으면 판정하지 않는다.** 단독 런은 "관찰"이지 "판정"이 아니다.
- **후견지명 금지.** 저점·고점을 안 뒤의 "그때 이랬으면" 계산은 근거가 아니다.
  반사실을 쓰려면 **규칙대로 앞에서부터** 굴려서 그 규칙이 그 구간에서 몇 번 발사했을지까지 세라.
- 한 창의 결과를 전체 성질로 일반화하지 마라. 극한창만 돌리면 **비용만 측정되고 편익은 미측정**이다.
- CSV가 공용 폴더에 append 되는 구조다. **런 전 CSV 삭제**가 안 됐으면 후행 런 기준으로만 읽고 각주를 달아라.

## 출력 형식

```
[사전확인] 부호 규약 실증 결과 (샘플 인용)
[런 제원] 기간·씨앗·설정값 (리포트 입력란 실측)
[성적] 총수입 / EqDD / BalDD / PF / Sharpe
[다리 분류] 방패방향 / 물타기 / 평시 / 마감절단 별 건수·손익
[사망 사슬 또는 승인] 시간순 재구성
[A/B 판정] 대조군 있음/없음 → 판정 또는 판정불가
[데이터 품질 각주] 신뢰할 수 없는 필드
```
