# VT마켓 "비정상 주문 과다" 3차 차단 — 서버 트래픽 전수 감사 (2026-08-05)

투입: 서버 트래픽 감사관 + 제재 법의학자 (병렬·독립). 대상: v5.5.5 internal (19,090행).

## 핵심 결론
1. **§16 카운터(CanSendOrder/MarkSent)는 진입 계열만 계수한다.** TP수정(Modify)·청산(Close) 계열은 사실상 전부 계수 밖 — 스파이크 국면에서 브로커가 보는 요청의 70~90%가 EA 자체 유량계에 안 잡힌다. §16 캡은 20건/10초를 지킨다고 믿지만 **실제 VT 관측치는 150~300건/10초**.
2. **ServerReady 4축에 `ACCOUNT_TRADE_ALLOWED`(계좌 read-only 축)가 빠져 있다** — VT가 read-only 제재를 걸어도 EA는 계속 노크 → "제재 → 계속 두드림 → 재제재" 악순환. 3회 반복 차단과 정확히 부합.
3. **최악 무스로틀 루프 = CRUSH 잔여 재청산(L2956~2965)**: 매틱 CloseAll, GX 쿨다운 기록만 하고 미참조. read-only 국면과 겹치면 시간당 수만 건 거절 로그.

## 진범 랭킹 (법의학)
1. **청산 연쇄 버스트** — 전 청산 경로 중 per-leg CanSendOrder 1/11곳(R1뿐), MarkSent 0곳, GRIND_CLOSE_RETRY=5 무간격, REQUOTE류(10004/10020/10021)는 IsTerminalRetcode 밖이라 다리당 5연타 → 12다리 콤보 리쿼트 시 한 틱 60건.
2. **R1 미적용 지대 반복 거부** — ScanAndFixZeroTP(3초 주기, 기통과 가드 없음 → 시간당 1,200건 상한 무한 INVALID_STOPS), PM_Recalc(SR·가드·계수 전무), freeze/stops level 검사 파일 전체 0건.
3. **자정·금요 무게이트 일제 사격** — 자정 스왑 재동기(OnTimer 직결, 세션게이트 없음 → 매일 00:00 MARKET_CLOSED 후보), WLU FLATCUT(금요 마감 30분 전 전 포지션 무제한).

기각: 웹훅/HTTP 계열(H5) — 거래 서버와 물리 분리, 평시 분당 POST 2건 수준.

## VT 저널 판별 지문 (재가동 전 필수 확인)
- retcode 분포: **10016이 3초 등간격** = ScanAndFixZeroTP / **10018이 00:00±2분 클러스터** = 자정 재동기 / 동일 티켓 같은 초 2~5연발 = CLOSE_RETRY 연타
- 10초창 요청 수가 20건(§16 캡) 초과 = 계수 밖 트래픽 증거
- 차단 3회의 발생 시각 ↔ (자정/금요 컷엣지/급변동/월요 개장) 대조
